# Changelog

All notable changes to AnyFont. The newest version comes first. Each version's section is also the text of its
GitHub release (the release workflow copies the section that starts with `## <version>`), and AnyFont shows it in
the update prompt.

## 0.1.0 – 2026-11-16

First release of AnyFont, a font manager for Windows 10 and 11 (64-bit).

### Browse and preview
- Every font on the PC in "My fonts", each previewed in its own typeface with your sample text, grouped by family.
- Search, preview size slider, recently used fonts, Latin names, font names drawn in their own font.
- Filters: font status (installed, not installed, protected system fonts, duplicates), embedding rights, technology,
  weight, width, style, character range and OpenType features.
- Font properties panel: glyph grid with filters and alternates, font information, variable font axes and instances.

### Organise
- Libraries: add font folders, collections (Favorites and your own), add to / remove from collections, rename.
- Show duplicate fonts, open the font file location, import and export folders and collections.
- PANOSE font matching for missing fonts (with exceptions and permanent or temporary substitutions) and Type 1
  replacement suggestions.

### Install and remove
- Install for all users (one administrator prompt) or only for you, uninstall, delete to the Recycle Bin.
- Protected system fonts are never uninstalled or deleted; fonts in use offer Reboot now, Reboot later or Ignore.
- Get More: browse and download open-licence fonts from the Google Fonts catalog, then install them.

### Everything else
- Four themes (Light, Medium, Dark, Black), interface scaling and 15 interface languages.
- Updates: a message at start-up when a new version exists (install now or later) and Help ▸ Check for Updates.
- Help ▸ Report a Bug and Submit Ideas and Feedback send straight to GitHub, no GitHub account needed.

### Known limits
- WOFF2 files are listed but not previewed or installed.
- The installer and program are not code-signed yet, so Windows SmartScreen may ask for confirmation.
